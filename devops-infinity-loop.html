The CALMS Framework

The Core Pillars of DevOps Success (DevOps သည် Tool တစ်ခုတည်းမဟုတ်ဘဲ Culture နှင့် ပူးပေါင်းဆောင်ရွက်မှုအပေါ် အခြေခံသည်)

⭐ Core Pillar
C
Culture
အပြန်အလှန်ယုံကြည်မှု၊ ပူးပေါင်းဆောင်ရွက်မှုနှင့် Blameless Mindset ဖြင့် Dev နှင့် Ops ကြား အတားအဆီးများကို ဖြိုခွင်းခြင်း။
A
Automation
CI/CD ပိုက်လိုင်းများ၊ အလိုအလျောက် Testing နှင့် Infrastructure as Code (IaC) ဖြင့် လူအားလျှော့ချခြင်း။
L
Lean
မလိုအပ်သော အလေအလွင့် (Waste) များကို လျှော့ချပြီး Batch size သေးသေးဖြင့် မြန်မြန်ဆန်ဆန် စဉ်ဆက်မပြတ် ပေးပို့ခြင်း။
M
Measurement
DORA metrics၊ MTTR၊ System Logs နှင့် Deployment Frequency စသည့် Data များအပေါ် အခြေခံ၍ စဉ်ဆက်မပြတ် တိုးတက်စေခြင်း။
S
Sharing
အတွေ့အကြုံ၊ သင်ခန်းစာများနှင့် အသိပညာဗဟုသုတများကို Team အချင်းချင်း ပွင့်လင်းစွာ ဝေမျှသည့် Feedback Loop တည်ဆောက်ခြင်း။

Why "Culture" Comes First in CALMS:

DevOps starts with people, not tools. ကမ္ဘာ့အဆင့်မီ Automation Tools (CI/CD, Kubernetes) တွေရှိနေရင်တောင်မှ Dev နဲ့ Ops အသင်းအဖွဲ့ကြားမှာ ပူးပေါင်းလိုစိတ် (Collaboration) နဲ့ တာဝန်ယူလိုစိတ် (Shared Ownership) ရှိတဲ့ Culture မရှိရင် DevOps Implementation ဟာ မအောင်မြင်နိုင်ပါဘူး။ ဒါကြောင့် CALMS ရဲ့ အစအဦး Culture ဟာ အခြေခံအကျဆုံး Foundation ဖြစ်ပါတယ်။
